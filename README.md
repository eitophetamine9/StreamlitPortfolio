## Highlights Available on the Streamlit App

- **Interactive Skills Matrix**: Dynamic domain filters, proficiency slider, bar charts, and tabular view.
- **Featured Projects Grid**: Detailed breakdowns, toolsets, and live links for AnchorPod, Spirit Contract Evo, Phlegmatic, Luck in the Dungeon, and CyberType.
- **Accredited Certifications**: Verified credentials and certificates in C, Java, PSITE, and OWASP.
- **Real-time GitHub Contributions**: Live commit heatmaps and open-source activity.
- **Direct Feedback Channel**: Responsive contact form with instantaneous feedback receipts.

## Running Locally

```powershell
pip install -r requirements.txt
streamlit run app.py
```

Access the local server at `http://localhost:8501`.
